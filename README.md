# Weather Application 🌤️

A weather application built using React, Vite, Material-UI, and vanilla CSS.

## Features
- Search any city and get live weather data
- Temperature, humidity, wind speed display
- Clean and responsive UI

## Technologies Used
- React
- Vite
- Material-UI
- Vanilla CSS
- OpenWeatherMap API

## How to Run
1. Clone the repository
   git clone https://github.com/seema1406/Weather-App.git
2. Install dependencies
   npm install
3. Run the project
   npm run dev
